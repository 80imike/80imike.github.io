还在为投简历而熬夜吗？还在为重复性的求职操作而苦恼吗？

一个来自 GitHub 的开源神器 loks666/get_jobs 正在改变无数求职者的命运！

这个项目被称为「AI 找工作助手」，支持全平台自动投简历脚本，覆盖 Boss 直聘、前程无忧、猎聘、拉勾、智联招聘等主流招聘平台。让我们深入了解这个让求职变得如此高效的开源利器。

项目地址：

  • GitHub: https://github.com/loks666/get_jobs
  • Gitee 镜像: https://gitee.com/lok666/get_jobs

💡 核心功能一览：AI 赋能的全能求职助手

🧠 AI 智能匹配与个性化招呼语

项目最大的亮点是 AI 智能匹配功能，能够检测岗位匹配度，并根据 JD 自动撰写个性化的打招呼语（仅限 Boss 直聘）。想象一下，每个岗位都有专门为你量身定制的招呼语，这种个性化程度远超传统的模板化投递。

AI 功能的工作原理是：

  • 分析岗位描述与你的技能匹配度
  • 自动生成符合岗位要求的打招呼语
  • 智能过滤不匹配的岗位，避免无效投递

📷 图片简历自动发送

Boss 直聘可在发送打招呼语后自动发送图片简历，无须等待 HR 索要简历，有效提高回复率。这个功能解决了很多求职者的痛点：HR 往往会要求看简历，而自动发送功能让这个过程无缝衔接。

⏰ 定时投递：解放你的时间

支持一键投递所有平台，可设置定时投递，第二天自动重新投递，省时省力。你可以：

  • 设定每日投递时间
  • 自动重复投递新岗位
  • 无需手动操作，程序自动完成

🔎 智能过滤：精准投递

自动过滤不活跃 HR、猎头岗位、目标薪资，让你的简历投递更精准。这意味着：

  • 避开半年未活跃的 HR
  • 排除不符合期望薪资的岗位
  • 智能识别猎头岗位
  • 自动建立黑名单机制

📢 实时通知：掌控投递进度

通过企业微信消息推送，实时掌握简历投递情况，不错过任何机会。每次投递完成后，你都能收到详细的投递报告，包括成功数量、失败原因等信息。

🛠️ 安装配置：5 分钟即可上手

环境准备

在开始使用之前，你需要准备：

  1. Chrome 浏览器：必须是从 Chrome 官网下载的对应版本
  2. Java 运行环境：确保系统已安装 JDK
  3. 网络环境：必须要关闭墙外代理，由于主要针对国内平台，墙外代理会导致页面加载缓慢

快速安装

目前程序自动判断系统环境，使用对应的 chromedriver，并进行浏览器操作，大大简化了配置过程。

🎯 使用方法：让投简历变得如此简单

各平台特色功能

1. Boss 直聘（强烈推荐）

每日仅可发起 100 次新聊天，活跃度还行，但是每日投递次数太少。尽管有数量限制，但质量很高：

  • AI 生成个性化招呼语
  • 自动发送图片简历
  • 智能黑名单更新

2. 猎聘（量大推荐）

默认打招呼无上限，主动发消息有上限，虽然成功率不高，好在量大，较为推荐。特点：

  • 需要在手机 App 设置打招呼语
  • 微信扫码登录
  • 投递量大，适合广撒网

3. 51job（不推荐）

投递有上限，且限制搜索到的岗位数量，没什么活人。虽然支持，但效果一般。

4. 拉勾（效率较低）

投递无上限，会限制投递的频率，没什么活人而且投不了几个岗位。适合作为补充渠道。

5. 智联招聘（备选）

投递上限 100 左右，岗位质量较差，走投无路可以考虑。

定时投递设置

目前默认 Boss 会定时投递两次，可以修改相关代码修改时间。你可以：

  • 设置每日自动投递时间
  • 配置多平台同时投递
  • 自定义投递间隔

企业微信通知配置

  1. 创建企业微信群聊
  2. 添加机器人获取 URL
  3. 配置 .env 文件中的 HOOK_URL
  4. 设置 config.yaml 中 bot.is_send 为 true

完成配置后，每次投递结束都会收到详细的投递报告。

⚠️ 使用注意事项

重要提醒

  1. 服务器部署限制：本项目不支持服务器部署，如招聘网站发现访问者为服务器 IP，不会返回任何网站数据

  2. Boss 直聘使用建议：最重要的事情：不要依赖程序投递 Boss！手机上的 Boss，比本程序网页端靠谱得多

  3. 频率控制：避免过于频繁的操作导致账号被封
